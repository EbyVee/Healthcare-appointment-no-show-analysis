# Healthcare-appointment-no-show-analysis
Interactive Power BI dashboard analysing healthcare appointment no-show trends and identifying factors influencing patient attendance.

## 📖 Project Overview

This project presents an interactive Power BI dashboard developed to analyse healthcare appointment attendance and identify patterns associated with missed appointments (no-shows).

The dashboard provides operational insights to help healthcare organisations reduce missed appointments, improve patient attendance, and enhance service efficiency through data-driven decision-making.


##  Project Objectives

The objectives of this project were to:

* Analyse appointment attendance patterns.
* Calculate key performance indicators (KPIs) for appointment performance.
* Identify demographic and operational factors associated with missed appointments.
* Present insights using an interactive Power BI dashboard.
* Demonstrate data analysis and visualisation skills using Power BI.

---

##  Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Microsoft Excel

---

##   Key Performance Indicators (KPIs)

The dashboard includes:

* Total Appointments
* Attended Appointments
* Missed Appointments
* No-Show Rate (%)

---

##  Dashboard Analysis

The dashboard analyses no-show rates by:

* Gender
* Age Group
* Day of Week
* SMS Reminder Status

Interactive slicers allow users to filter the dashboard for deeper analysis.

---

##   Key Insights

The dashboard enables users to:

* Identify patient groups with higher no-show rates.
* Evaluate the effectiveness of SMS reminders.
* Detect weekly attendance patterns.
* Monitor overall appointment performance.
* Support operational planning using data-driven insights.

---

##  Recommendations

Based on the analysis, healthcare providers could:

* Increase the use of appointment reminders for high-risk groups.
* Monitor attendance trends by day of week when planning clinics.
* Develop targeted interventions for demographic groups with higher no-show rates.
* Continue monitoring attendance KPIs to support service improvement.
